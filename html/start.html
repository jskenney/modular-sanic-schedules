Endpoints below require an API key, key is ignored if a valid web session is found.
Access Endpoints
/auth/<apikey>/access/list/<user>                    - Lists Accesses (requires admin for other users)
/auth/<apikey>/access/add/<user>/<access>/<value>    - Add/Modify Access (requires admin)
/auth/<apikey>/access/remove/<user>/<access>/<value> - Remove Access (requires admin)
Course Schedule Endpoints



Schedules

Semester Information
/sched/<apikey>/school/<schoolname>
example: /sched/<apikey>/school/SCHOOL1
example: /sched/<apikey>/school/SCHOOL2

Course Information
/sched/<apikey>/course/<coursenum>
example: /sched/<apikey>/course/COURSE1
/sched/<apikey>/course/<coursenum>/<instructor>
example: /sched/<apikey>/course/COURSE1/INSTRUCTOR1
/sched/<apikey>/course/<schoolname>
example: /sched/<apikey>/course/SCHOOL2

Current user Info and Class Schedules
/sched/<apikey>/user
example: /sched/<apikey>/user
/sched/<apikey>/user/<user>
example: /sched/<apikey>/user/USER1

Student Info and Class Schedules
/sched/<apikey>/student
example: /sched/<apikey>/student
/sched/<apikey>/student/<username>
example: /sched/<apikey>/student/STUDENT1
/sched/<apikey>/student/<username>/<course>
example: /sched/<apikey>/student/STUDENT1/COURSE1
/sched/<apikey>/student/<schoolname>
example: /sched/<apikey>/student/SCHOOL2

Instructor Info and Class Schedules
/sched/<apikey>/instructor
example: /sched/<apikey>/instructor
/sched/<apikey>/instructor/<instructor>
example: /sched/<apikey>/instructor/INSTRUCTOR1
/sched/<apikey>/instructor/<instructor>/<course>
example: /sched/<apikey>/instructor/INSTRUCTOR1/COURSE1
/sched/<apikey>/instructor/<instructor>/<course>/<section>
example: /sched/<apikey>/instructor/INSTRUCTOR1/COURSE1/2141
/sched/<apikey>/instructor/<schoolname>
example: /sched/<apikey>/instructor/SCHOOL2

Room Utilization
/sched/<apikey>/room/<roomname>
